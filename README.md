# OOP_ArcShot – Basketball 2D

| Folder | What it is |
|---|---|
| `ArcShot/` | **Current version (v3):** main menu, shared UI theme, the reskinned Messenger game and the 3x3 mode with the retro pixel renderer, layups/dunks, referees and FIBA 3x3 fouls. Integration steps from v2: `ArcShot/INTEGRATION_GUIDE.md`. Start here: `ArcShot/README.md`. |
| `basketballV1 alpha 0.1.10/` | Original Messenger-style game (kept unchanged for history). |
| `basketballV1 alpha 0.1.9/` | Earlier original version (kept unchanged). |

Quick start: `cd ArcShot` then `./build.sh` (macOS/Linux) or `build.bat` (Windows). Needs JDK 10 or newer. Self-tests: `./build.sh test`.
